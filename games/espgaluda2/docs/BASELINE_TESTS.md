# 验收矩阵

G2 的合集迁移基线已收尾。六种 PLAY 模式进入、本地／网络录像、成绩与显示、稳定节拍已有下述证据；同进程三次进入第一关／返回／重新进入由用户实测完成。系统音量已跨进程读回，模式设置按已有观察与用户接受范围收尾，不再追加测试。实体输入、更多角色、训练、正式服务与长期稳定性继续列入合集回归，不写成已通过。

## 初始化工具

Python 自制数据回归覆盖 XEX 大端字段、非覆盖导入、源码边界、固定依赖、归档安全、八模块生成声明、构建/PDB 身份、短回调候选筛选、日志分析、社区元数据扫描和服务端成绩存储。原生 settings、input、hashing、async_logging、guest_video_timing、frame_timing、time_zone、community_http、community_service 九组回归通过；输入包含 UTF-8、多键、斜向、扳机、失焦、死区、事件合并、短按单次采样与长按正常释放。异步日志测试覆盖慢写入、有界队列、丢弃统计与显式 flush；客体视频计时覆盖不同计时频率、刷新率、时间缩放和追赶循环，帧时间统计覆盖窗口边界、长帧、直方图溢出、峰值时间点与时钟回退。时区测试覆盖有符号分钟偏差、半小时时区、标准／夏令时四字节规则，并直接调用安装 SDK 的 XConfig 接口核对当前 Windows 时区、长度查询及小缓冲区边界。

八项无窗口启动检查通过：首次创建默认配置、保留既有配置、拒绝冲突绑定、拒绝存档与数据路径重叠、拒绝错误 XEX，以及社区空端点拒绝、不安全 HTTP 拒绝、有效社区配置在不联网条件下通过预检。中文空格路径使用进程 UTF-8 manifest。外部崩溃辅助程序已通过合成上下文检查，生成文本摘要与 DMP，不触发真实游戏异常或系统错误窗口。

本地完整数据已导入且与原目录逐文件一致：155 个文件、677,185,607 字节。八个 XEX 的元数据在 config/game-inputs.json；完整盘点和复制核对在本地 .local，未执行游戏代码。

## G2 社区接入

通用 HTTP worker 在原基线从虫姬二维护源码抽出到 src/community，合集现位于 common/community，来源提交见 docs/SOURCE_ORIGINS.json；未复制其榜单或录像布局。原生端点／昵称与取消单测通过，九类本机 loopback 集成检查通过：GET、POST、64 位分数文本、禁止重定向、坏 JSON、响应大小上限、有界队列、非阻塞发起与退出取消。慢请求时 40 次发起总耗时约 0.03 ms，23 个超限任务被拒绝，16 个等待任务取消，活动请求停止约 0.8 ms；这些是测试机样本，不是跨机器时延保证。

受支持 default.xex 及分析段哈希核对后，静态确认 84 个 view、17 项提交属性、严格个人新高筛选、前十名录像候选及玩家确认，并确认 G2 的顺序是先成绩后录像。原生系统接口边界、错误退出和数据映射注意事项见 [模块分析](PROGRAM_LAYOUT.md#原生社区流程)。元数据扫描六项自造数据回归通过；这些不是联网动态验收。

## 后续每个模式必须填写的项目

模式名称按实际菜单登记，并覆盖各角色及该模式可用的特殊操作。每个结果注明源码/构建、程序哈希、隔离 profile 和日志路径。

1. 选人确认进入玩家第一关，不使用演示画面作证据。
2. 普通射击/连射、特殊操作、死亡复活、局末与续关。
3. 返回菜单与重复进入，跨模式切换、加载和卸载。
4. 设置/成绩保存、正常重启读回；录像录制、保存、跨进程完整播放。

CAVE PC Collection v0.3

开始游玩
完整解压后，双击根目录 CAVE-PC-Collection.exe，选中游戏，点击“启动游戏”。
启动游戏.bat 是备用入口。不要在压缩包内运行，也不要只复制一个 EXE。
需要 Windows 64 位及显卡厂商提供的正式驱动；C++ 运行库已随程序附带。
虫姬二、ESPGaluda II、最大往生使用 D3D12，绊地狱和大往生使用 Vulkan。

游戏数据
内部完整版包含上述五款游戏的受支持数据，以及虫姬二的 Black Label／Ver1.01。
对外程序包不含 ROM：可通过启动器选择自己的数据目录，或放到以下默认位置。
只安装一款游戏也能使用；ESP Ra.De. 暂未接入。

  game-data/futari/       虫姬二本体，default.xex 位于根目录
  game-data/futari/dlc/   Black Label 和 Ver1.01，保留原内容目录结构
  game-data/espgaluda2/   完整解包数据，含 default.xex、模式 XEX、res/DISKDATA
  game-data/ketsui/       CUSA09062-app、CUSA09062-patch（1.02）两个目录
  game-data/sdoj/         光盘本体，含 default.xex、CA022100.bin、CA022110.bin
  game-data/daioujou/     CUSA32997／01.04 合并数据，eboot.bin 位于根目录

大往生需完整的合并更新数据，不能只复制 eboot.bin 或单个 PRX。
最大往生使用原版光盘资源，不混入 default.xexp、.binp 更新或音乐补丁。
原 ISO、解包工具、系统更新和 Project.gp4 不是玩家运行文件。
两款 PS4 作品首次启动会在 prepared/<游戏>/ 自动准备镜像，原始数据不改写。

配置与按键
启动器支持中文、日文和英文；右上角语言菜单可切换并保存。
横幅以官方日文标题为主、英文为副标题，不随界面语言改变。
页头可改启动全屏和排行榜昵称，点击“保存”；启动游戏前也会保存快捷设置。
“配置文件”打开唯一的 config.ini，可修改显示、音量、键盘、手柄和联网设置。
外部编辑保存后点“刷新”；游戏内的设置仍通过各游戏自己的菜单保存。

默认键盘：方向键移动；Z／X／C／V 对应手柄下／右／左／上方按钮；Enter 开始；
Backspace 为 Select／Touchpad；A／S 为 L1／R1；Q／W 为 L2／R2。
投币、确认、射击和炸弹的具体动作，以各游戏内的按键设置为准。
F11／Alt+Enter 切换全屏，Alt+F4 关窗，F8 在运行日志中加入时间标记。
手柄由 SDL 自动识别，可在 config.ini 中调整键盘绑定及摇杆死区。

联网
默认开启，不用注册。昵称默认 Player，建议通过启动器或 config.ini 改成自己的名字。
[community] 的 enabled = false 可关闭，endpoint 默认 https://xiaolu.life/cave/api/v1。
五款游戏分别使用独立榜单；联网会发送昵称、成绩和适用的录像。
通过游戏原生界面提交成绩、看榜和下载录像，不是登录微软或 Sony 的账号服务。
最大往生的团队评分、大往生的 CUSTOM 成绩提交不在当前支持范围内。
关闭联网不影响本地游玩、存档和已有本地录像。

存档与更新
存档、录像和适用的待传记录在 user-data/<游戏>/；更新时保留该目录和 config.ini。
游戏数据可以继续使用，不要用旧版 prepared 或缓存覆盖新版本。
修改游戏内设置后，退出设置页、等待自动保存完成再关窗。
最大往生商店保留通过游玩赚取金币的原生解锁，购买后退出商店等保存完成。
Alt+F4 不保证保存当前局或尚未写入的修改。

问题反馈
请附游戏、模式、角色、操作步骤、大致时间及 release.json；异常后可按 F8 标记。
在启动器点“日志”，找到 logs/<游戏>/ 最近一次 run-*，关闭游戏后将整个文件夹
压缩发给提供本包的人。PS4 日志为 stdout.jsonl／stderr.txt，360 另有崩溃报告。
不要只发最后一行错误；保存／录像问题可另附相关槽位的副本。
日志可能包含昵称、机器信息和本地路径，发送前可查看。

已知限制
PS4 客体的完整退出清理仍未完成，受控关窗会返回启动器并在日志记录状态。
本版优化了绊地狱／大往生的任务交接及画面输出，未覆盖全部硬件或场景。
最大往生仍保留原作输入／渲染顺序，没有接入上游降延迟补丁；小飞机击毁声
目前为未确认反馈，音乐补丁未启用。这些项目不作为已修复内容介绍。
代表性流程不等于所有模式、角色、设备和长期稳定性均已覆盖。

开发
内部版的 source/ 为独立 Git，从 source/FOR_AGENT.md 开始。
编译请用较短的英文目录；玩家运行和游戏数据可以使用中文路径。
对外包不含源码，对应源码附件可向包提供者索取，不需要私有仓库权限。
许可证及对应源码信息在 licenses/ 与 SOURCE.txt。

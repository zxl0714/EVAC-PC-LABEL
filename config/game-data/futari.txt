虫姫さまふたり Ver.1.5 / Mushihimesama Futari
Xbox 360

将完整解包数据的内容放在此目录，直接看到 default.xex、media/ 等文件。
保留其余文件和内部目录。可选 Black Label／Ver.1.01 DLC 放入此处的 dlc/，
保留 DLC 原有目录和文件名。推荐结构：
  dlc/0000000000000000/435A07D7/00000002/
    496F816DD4B53DAEFF931838B6C69831AAD7663043/
      spa.bin
      Rom/cg_black.bin
      Rom/cg_blackhi.bin
      Rom/dropprm.bl
    9893A78CA6062B935BD1F53EA43CFD546B7246DF43/
      ver101_key.bin
前一项是 Black Label，后一项是 Ver.1.01，可分别安装。
已有 dlc/00000002/<包目录>/ 也能识别，不必移动。
如果 DLC 是单个无扩展名的容器，先用包内 tools/Extract-Dlc.ps1 提取：
  .\tools\Extract-Dlc.ps1 -InputPackage "D:\Games\DLC容器" -OutputDir "D:\GameExtract\futari-dlc"
父目录 D:\GameExtract 须已存在，输出目录须不存在。再将提取出的文件按上方放置。
在启动器选中本作，点击“详情”可查看 DLC 实际查找位置和各项状态。
默认 dlc_dir = auto 查找本体目录下的 dlc/；旧配置如写了固定路径会保留。
不安装 DLC 也可游玩 Ver.1.5 本体；dlc/ 可以留空或不存在，无须改配置。
不要多套一层目录，也不要将原文件重命名；例如正确位置为
game-data/futari/default.xex，而不是 game-data/futari/解压目录/default.xex。
完成后在启动器点击“刷新”。不必安装其他游戏，也不必修改配置路径。
ISO 需先提取为游戏文件；ZIP 需解压，不要将镜像或压缩包本身放在这里。

Place the complete extracted Xbox 360 game here, with default.xex directly
inside this folder. Keep media/ and all remaining files and subfolders.
Optional Black Label / Ver.1.01 content goes in dlc/. Use the tree above:
496F... is Black Label (spa.bin plus all three Rom/ files); 9893... is Ver.1.01.
Either package can be installed independently. An existing
dlc/00000002/<package-folder>/ layout also works without moving it.
For an original, extensionless DLC container, run from the collection root:
  .\tools\Extract-Dlc.ps1 -InputPackage "D:\Games\dlc-container" -OutputDir "D:\GameExtract\futari-dlc"
Create D:\GameExtract first; the output folder must not exist. Place its extracted
contents in the matching package folder shown above. Windows PowerShell 5.1 is enough.
Select Futari and click Details to see the DLC search path and each package's status.
The default dlc_dir = auto follows the base game's dlc/ folder. Explicit paths in
older configurations are preserved; change the value to auto to follow the base.
Ver.1.5 works without DLC. Leave dlc/ empty or absent; no config change is needed.
Do not rename game files or add a wrapper folder: the entry belongs at
game-data/futari/default.xex, not game-data/futari/extracted-folder/default.xex.
Click Refresh in the launcher.
Other games are optional. Extract ISO/ZIP contents first, not the archive itself.

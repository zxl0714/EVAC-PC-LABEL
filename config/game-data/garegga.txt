バトルガレッガ Rev.2016 / Battle Garegga Rev.2016
PS4 / CUSA10207 / 01.00 (KR)

Extract the base PKG with tools/Extract-PS4.exe, then copy the contents of uroot here:

game-data/garegga/
  eboot.bin
  ps4data_info.psb.m
  ps4data_body.bin
  *.prx
  2000/movie/
  sce_module/
  sce_sys/


双击 tools/Extract-PS4.exe，选择韩版 01.00 本体 PKG 和新输出目录，点击 Extract。
完成后点 Open game files，将全部内容复制到 game-data/garegga/，再在启动器点击刷新。

Default controls: V = Credit; Enter = Start; C/S = Shot; Z/A = Weapon; X = Formation; Backspace = Pause menu.

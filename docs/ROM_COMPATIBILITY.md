# ROM 功能兼容性矩阵

行是 EVAC PC LABEL 给游戏新增、解锁或扩展的功能。样本表头按「游戏版本 · 数据来源或格式」命名，有地区差异时注明地区。曲包、DLC 文件和运行设置是验收条件，记录在表下。

| 标记 | 含义 |
| --- | --- |
| ✓ | 该样本上的这项功能已实测通过。 |
| ? | 该样本上的这项功能尚未验证。 |
| X | 实测确认该样本与这项功能不兼容。 |

矩阵随开发和实测更新。运行时所需程序和资源一致的转储共用一列。原版模式、缺陷修复和通用游玩回归见[验收矩阵](TEST_MATRIX.md)。样本见 [ROM 库](IMPLEMENTATION_PLAN.md#v0911-兼容性练习存档与文件上传)。

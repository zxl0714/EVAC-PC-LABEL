# EVAC PC LABEL v0.10.1

- **启动器新增大屏模式。** 点击底部的「大屏模式」或按 `F11` 切换，启动器会记住上次使用的模式。桌面和大屏都支持用手柄或街机摇杆选游戏、启动游戏。[#24](https://github.com/zxl0714/EVAC-PC-LABEL/issues/24)
- **《怒首领蜂最大往生》支持 Xbox 360 光盘版 TU 1.01。** 将 TU 文件放到 `default.xex` 同目录，打开启动器后会自动解包。
- **《空战之路 Rev.2016》新增日版 01.07 支持。** 日版和韩版共用社区排行榜，可以互相下载和播放录像。
- **改善 PS4 游戏的数据兼容性。** 已支持的游戏版本可以识别更多工具导出的数据。
- **改善《大往生》Death Label 进入和重进时的稳定性。** 修复游玩中切换全屏会退回主菜单的问题。

## English

- **Added Big Picture mode.** Use the button at the bottom of the launcher or press `F11` to switch modes. The launcher remembers your last mode. Controllers and arcade sticks can select and launch games in both modes. [#24](https://github.com/zxl0714/EVAC-PC-LABEL/issues/24)
- **Added Xbox 360 disc TU 1.01 support for DoDonPachi SaiDaiOuJou.** Place the TU file next to `default.xex` and the launcher will extract it automatically.
- **Added support for the Japanese 01.07 release of Battle Garegga Rev.2016.** The Japanese and Korean releases share community leaderboards and can download and play each other’s replays.
- **Improved PS4 game data compatibility.** Supported game versions now accept dumps from more tools.
- **Improved stability when entering and re-entering Death Label in DaiOuJou.** Fixed an issue where toggling fullscreen during a run could return you to the main menu.

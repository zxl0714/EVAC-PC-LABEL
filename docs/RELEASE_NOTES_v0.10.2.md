# v0.10.2

- 《最大往生》可从启动器打开 eandis 的 SDOJ-Recomp。将官方 Windows ZIP 解压到 `external/SDOJ-Recomp/`，再点桌面版封面右下角的 `eandis` 开关。大屏模式沿用这项选择。[#15](https://github.com/zxl0714/EVAC-PC-LABEL/issues/15)
- 启动器换用对应主机版本的封面，默认按 Xbox 360、PS4、PS2 排列。大屏封面等高显示，选中框贴合图面。[#27](https://github.com/zxl0714/EVAC-PC-LABEL/issues/27)
- 自动更新现在可以创建新版本所需的目录，并保留玩家的游戏数据、存档和配置。
- 启动器标题栏显示当前版本。[#26](https://github.com/zxl0714/EVAC-PC-LABEL/pull/26)

## English

- SaiDaiOuJou can launch eandis’s SDOJ-Recomp. Extract the official Windows ZIP into `external/SDOJ-Recomp/`, then use the `eandis` switch on the desktop game card. Big Picture follows the same selection. [#15](https://github.com/zxl0714/EVAC-PC-LABEL/issues/15)
- The launcher uses covers from the original console releases and groups games by Xbox 360, PS4, and PS2 by default. Big Picture aligns covers by height and frames the selected artwork. [#27](https://github.com/zxl0714/EVAC-PC-LABEL/issues/27)
- Automatic updates can now create directories required by new versions while preserving game data, saves, and settings.
- The launcher title bar shows the installed version. [#26](https://github.com/zxl0714/EVAC-PC-LABEL/pull/26)

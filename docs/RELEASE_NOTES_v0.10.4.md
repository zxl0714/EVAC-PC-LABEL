# EVAC PC LABEL v0.10.4

## English

- Added support for the US PS2 release of R-Type Final. Select the folder containing your ISO in the launcher. [Game data guide](GAME_DATA.en.md#rtype-final)
- Added disk read-ahead to reduce stuttering in PS2 games.
- Fixed an issue that could drop ESPGaluda to around 30 FPS with VSync enabled.
- Improved compatibility when entering Death Label from the PS4 version of DaiOuJou. If it still crashes after updating, please send a fresh report using **Upload logs** in the launcher.

## 简体中文

- 新增 PS2 美版《R-Type Final》。在启动器中选择 ISO 所在的目录即可游玩。[游戏数据说明](GAME_DATA.md#rtype-final)
- 增加磁盘预读，减少 PS2 游戏内的卡顿。
- 修复《ESPGaluda》开启垂直同步后帧率可能降至约 30 FPS 的问题。
- 改善了从 PS4 版《大往生》进入 Death Label 时的兼容性。如果更新后仍然闪退，麻烦通过启动器的「上传日志」再发一份。

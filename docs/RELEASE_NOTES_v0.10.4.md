# EVAC PC LABEL v0.10.4

## English

- Added support for the US PS2 release of R-Type Final. Select the folder containing your ISO in the launcher. [Game data guide](GAME_DATA.en.md#rtype-final)
- Fixed uneven frame pacing in ESPGaluda with VSync enabled.
- Improved Vulkan compatibility when opening DaiOuJou's Death Label mode. If it still crashes on your system, please send a new report through **Upload logs**.
- Published the HTTP API guide for recomp projects that want to connect to the EVAC PC LABEL community leaderboards. [Integration guide](COMMUNITY_INTEGRATION.md)

## 简体中文

- 新增 PS2 美版《R-Type Final》。在启动器中选择 ISO 所在的目录即可。[游戏数据说明](GAME_DATA.md#rtype-final)
- 修复《ESPGaluda》开启垂直同步时的画面卡顿。
- 改善《大往生》Death Label 启动时的 Vulkan 兼容性。如果仍遇到闪退，麻烦通过启动器的「上传日志」再发一份。
- 发布社区排行榜 HTTP API 文档，供其他重编译项目接入 EVAC PC LABEL 社区排行榜。[接入指南](COMMUNITY_INTEGRATION.md)

# 输入设置

启动器底栏加入「输入设置」，「配置文件」保留原入口。新窗口使用原生列表和按钮，沿用启动器的浅色。打开后默认编辑键盘，作用范围默认为「所有游戏」。选中游戏的名字出现在另一个范围选项中。

```text
┌ 输入设置 ──────────────────────────────────────────── × ┐
│ [ 键盘 ]   [ 手柄 / 摇杆 ]            [ 所有游戏 ▾ ]    │
│                                                          │
│ 游戏按钮                         当前绑定                 │
│ ┌──────────────────────────────────────────────────────┐ │
│ │  ↑ 方向上                      Up                    │ │
│ │  ↓ 方向下                      Down                  │ │
│ │  A  下方按钮                    Z                     │ │
│ │  B  右方按钮                    X                     │ │
│ └──────────────────────────────────────────────────────┘ │
│ [ 改键 ]  [ 清除 ]  [ 恢复默认 ]             [ 更多按键 ] │
│ 按下设备按键可以在这里查看对应的游戏按钮。                 │
│                                           [ 取消 ] [ 保存 ]│
└──────────────────────────────────────────────────────────┘
```

双击某行或选择「改键」开始录入。键盘等待下一次按键，Esc 结束录入。手柄页在列表上方显示已连接设备并允许切换，录入时先松开已有按键，再接受一次新的按钮、方向帽或轴动作。平时按设备上的键可查看目标按钮。断开设备时保留草稿，重连后可以继续。未识别的摇杆可从空白映射开始。

按键名跟随所选游戏的平台。Xbox 360 用 A/B/X/Y 和 Back，PS4 用 ×/○/□/△ 和触控板，PS2 用 PlayStation 按钮和 Select。共同范围显示方位。方向、四个面键、开始和返回默认可见，肩键、摇杆轴和狱门山式神方向按需展开。射击、炸弹等动作取决于原作的模式和键位设置。

每一行可以清除绑定或恢复。共同范围恢复为项目的默认键位或 SDL 的设备默认。单游戏键盘可逐行恢复继承。手柄按设备存一份映射，用「恢复本页」恢复该设备的继承关系。已有多键绑定显示在同一行，只有改动该行才写回。重复绑定提示冲突行，由玩家选择调整哪一项。切换设备、范围或页签保留草稿，保存时提交到 `user-data/config.ini`，下一次启动游戏生效。

评审时走三条路径。键盘用户应在打开窗口后通过双击和一次按键完成一行修改。摇杆用户应先看到设备状态，再用拨杆和按键检查或录入。单游戏玩家应能看见当前绑定是否继承，并在一处撤销自己的覆盖。中、英、日三种语言使用同一布局，小屏缩短列表并允许滚动。

手柄映射按 SDL 设备 GUID 保存。三套运行时由启动器在创建游戏进程时收到适用于该游戏的映射，继续使用各自现有的采样和事件处理方式。

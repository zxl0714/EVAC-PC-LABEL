# 输入设置

启动器底栏加入「输入设置」，「配置文件」保留原入口。新窗口使用原生列表和按钮，沿用启动器的浅色。打开后默认编辑键盘，作用范围默认为「所有游戏」。要给启动器选中的游戏单独改键，切到「当前游戏」。

```text
┌ 输入设置 ──────────────────────────────────────────── × ┐
│ [ 键盘 ]   [ 手柄 / 摇杆 ]            [ 所有游戏 ▾ ]    │
│                                                          │
│ 游戏按钮                         当前绑定                 │
│ ┌──────────────────────────────────────────────────────┐ │
│ │  ↑ 方向上                      Up                    │ │
│ │  ↓ 方向下                      Down                  │ │
│ │  A / ×                        Z                     │ │
│ │  B / ○                        X                     │ │
│ └──────────────────────────────────────────────────────┘ │
│ [ 改键 ]  [ 清除 ]  [ 恢复默认 ]                           │
│ 按下设备按键可以在这里查看对应的游戏按钮。                 │
│                                           [ 取消 ] [ 保存 ]│
└──────────────────────────────────────────────────────────┘
```

双击某行或选择「改键」开始录入。键盘等待下一次按键，Esc 结束录入。手柄页在列表上方显示已连接设备并允许切换，录入时先松开已有按键，再接受一次新的按钮、方向帽或轴动作。平时按设备上的键可查看目标按钮。断开设备时保留草稿，重连后可以继续。未识别的摇杆可从空白映射开始。

按键名跟随所选游戏的平台。Xbox 360 用 A/B/X/Y 和 Back，PS4 用 ×/○/□/△ 和触控板，PS2 用 PlayStation 按钮和 Select。共同范围并列显示 Xbox 和 PlayStation 的面键名称。列表直接显示当前设备和范围支持的全部按键。射击、炸弹等动作取决于原作的模式和键位设置。

每一行可以清除绑定。「恢复默认」一次恢复共用范围的键盘和所有手柄绑定。单游戏范围使用「恢复共用设置」，一次清除该游戏的全部独立绑定。保存时删除对应的配置项。录入已使用的键时，键会移到新的一行，原行的其他键保留。共同键盘设置与某款游戏的独立绑定冲突时，界面显示游戏名称，玩家可以先调整该游戏的绑定。切换设备、范围或页签保留草稿，保存时提交到 `user-data/config.ini`，下一次启动游戏生效。

评审时走三条路径。键盘用户应在打开窗口后通过双击和一次按键完成一行修改。摇杆用户应先看到设备状态，再用拨杆和按键检查或录入。单游戏玩家应能看见当前绑定是否继承，并在一处撤销自己的覆盖。中、英、日三种语言使用同一布局，小屏缩短列表并允许滚动。

手柄映射按 SDL 设备 GUID 保存。三套运行时由启动器在创建游戏进程时收到适用于该游戏的映射，继续使用各自现有的采样和事件处理方式。

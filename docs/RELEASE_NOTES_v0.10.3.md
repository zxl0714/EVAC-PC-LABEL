# EVAC PC LABEL v0.10.3

- 启动器新增《首领蜂》，可以从桌面或大屏模式启动 DonPachi Recomp。将作者发布的 Windows x64 程序解压到 `external/DonPachi-Recomp/`，再在启动器为《首领蜂》选择自己的美版 `donpachi.zip`。[下载 DonPachi Recomp](https://github.com/CapsLock4284/DonPachi-Recomp/releases/latest) · [#25](https://github.com/zxl0714/EVAC-PC-LABEL/issues/25)
- 完善《大往生》Death Label 的启动诊断。如果进入模式时闪退，重开启动器使用「上传日志」即可。
- 桌面启动器统一使用封面网格。使用旧横幅布局的玩家更新后会自动进入网格。
- 在游戏里按 `Esc` 或 `Start + 十字键上` 即可退出并返回启动器，可在「输入设置」里改键。[#29](https://github.com/zxl0714/EVAC-PC-LABEL/issues/29)
- 合集自带的游戏在全屏时会自动隐藏闲置的鼠标指针，移动鼠标时重新显示。[#31](https://github.com/zxl0714/EVAC-PC-LABEL/issues/31)
- 大屏模式适配竖屏机台，一屏显示一张大封面，用上下方向键切换游戏。[#30](https://github.com/zxl0714/EVAC-PC-LABEL/issues/30)

## English

- Launch DonPachi Recomp from the new DonPachi card in desktop or Big Picture mode. Extract the author's Windows x64 release to `external/DonPachi-Recomp/`, then select your own US `donpachi.zip` for DonPachi in the launcher. [Download DonPachi Recomp](https://github.com/CapsLock4284/DonPachi-Recomp/releases/latest) · [#25](https://github.com/zxl0714/EVAC-PC-LABEL/issues/25)
- Improved startup diagnostics for DaiOuJou's Death Label mode. If the mode crashes on entry, reopen the launcher and choose **Upload logs**.
- The desktop launcher now uses the cover grid. Players who previously selected the banner layout will see the grid after updating.
- Press `Esc` or `Start + D-pad Up` in a game to exit and return to the launcher. You can remap the shortcut under **Controls**. [#29](https://github.com/zxl0714/EVAC-PC-LABEL/issues/29)
- The built-in games hide the cursor while it is idle in fullscreen and show it again when the mouse moves. [#31](https://github.com/zxl0714/EVAC-PC-LABEL/issues/31)
- Big Picture adapts to portrait displays with one large cover at a time. Press Up or Down to switch games. [#30](https://github.com/zxl0714/EVAC-PC-LABEL/issues/30)

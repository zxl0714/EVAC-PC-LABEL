# EVAC PC LABEL v0.10.3

- 启动器接入 CapsLock4284 的 DonPachi Recomp。将作者发布的 Windows x64 程序解压到 `external/DonPachi-Recomp/`，再在启动器为《首领蜂》选择自己的美版 `donpachi.zip`。[下载 DonPachi Recomp](https://github.com/CapsLock4284/DonPachi-Recomp/releases/latest) · [#25](https://github.com/zxl0714/EVAC-PC-LABEL/issues/25)
- 增加了《大往生》Death Label 的诊断日志。部分玩家遇到的闪退仍难以定位，如果更新后再次遇到，麻烦通过启动器的「上传日志」再发一份，谢谢。
- 启动器移除了横幅布局，只保留网格布局和大屏模式。
- 新增退出游戏快捷键。在游戏中按 `Esc`（键盘）或 `Start + 十字键上`（手柄或摇杆），即可退出并返回启动器。快捷键可在「输入设置」中修改。[#29](https://github.com/zxl0714/EVAC-PC-LABEL/issues/29)
- 全屏时自动隐藏鼠标指针。[#31](https://github.com/zxl0714/EVAC-PC-LABEL/issues/31)
- 大屏模式适配竖屏机台，使用 2×2 封面网格。[#30](https://github.com/zxl0714/EVAC-PC-LABEL/issues/30)

## English

- The launcher now integrates CapsLock4284's DonPachi Recomp. Extract the author's Windows x64 release to `external/DonPachi-Recomp/`, then select your own US `donpachi.zip` for DonPachi in the launcher. [Download DonPachi Recomp](https://github.com/CapsLock4284/DonPachi-Recomp/releases/latest) · [#25](https://github.com/zxl0714/EVAC-PC-LABEL/issues/25)
- Added more crash diagnostics for DaiOuJou's Death Label mode. Some reported crashes are still hard to pinpoint. If you run into one again after updating, please send a fresh report using **Upload logs** in the launcher.
- Removed the banner layout from the launcher. The cover grid and Big Picture mode are available.
- Added an in-game exit shortcut. Press `Esc` on a keyboard or `Start + D-pad Up` on a controller or arcade stick to return to the launcher. You can remap the shortcut under **Controls**. [#29](https://github.com/zxl0714/EVAC-PC-LABEL/issues/29)
- The mouse cursor automatically hides in fullscreen. [#31](https://github.com/zxl0714/EVAC-PC-LABEL/issues/31)
- Big Picture uses a 2×2 cover grid on portrait displays. [#30](https://github.com/zxl0714/EVAC-PC-LABEL/issues/30)

# EVAC PC LABEL v0.9.9

- 大往生新增 **X Arrange(Xbox 360)** 曲集。在启动器选中大往生，点击「游戏数据…」导入 Xbox 360 版镜像，再到游戏内 BGM SET 选择。
- 游戏库支持拖动排序和右键隐藏游戏；点击眼睛图标可显示隐藏项。
- 启动器可后台下载更新，右上角出现红点后，点击即可重启更新。
- 新增 **Extract Xbox 360** 图形解包工具，选择 ISO 即可提取游戏文件。
- 扩展大往生和 ESP Ra.De. 的已解密 PS4 数据识别，支持两作的 1.00／1.04 版本。
- 修复大往生在部分电脑上载入时退出的问题。
- 修复虫姬二部分手柄按 Start 无法进入菜单，以及启动时可能崩溃的问题；统一 Xbox 360 按键事件的刷新和改键处理。
- 改键范围简化为「所有游戏／当前游戏」，修复拖动窗口后首次打开分辨率菜单异常。

## English

- Added **X Arrange(Xbox 360)** music for DaiOuJou. Select DaiOuJou in the launcher, import the Xbox 360 ISO from **Game data…**, then choose the set in the game's BGM SET menu.
- Drag games to reorder the library, or right-click to hide them. Use the eye icon to show hidden games.
- Updates download in the background. Click the red dot in the upper-right corner to restart and update.
- Added **Extract Xbox 360**, a graphical tool for extracting game ISOs.
- Expanded recognition of decrypted PS4 data for DaiOuJou and ESP Ra.De., covering versions 1.00 and 1.04 of both games.
- Fixed DaiOuJou exiting during loading on some PCs.
- Fixed Futari failing to leave the title screen with some controllers, and an intermittent startup crash. Xbox 360 key events now consistently refresh device state and apply remapping.
- Input settings now use **All games / Current game** scopes. Fixed the resolution dropdown misbehaving on its first opening after moving the window.

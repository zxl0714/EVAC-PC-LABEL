# EVAC PC LABEL v0.9.3

- 修复 PS4 存档恢复异常导致游戏无法正常加载的问题，异常记录会自动备份。
- 关闭 PS4 正常游玩时的 Vulkan 调试校验，减少额外开销。
- 完善崩溃信息和日志上传，方便定位玩家遇到的问题。
- 运行组件缺失或无法访问时，显示具体文件和处理方法。

## English

- Fixed PS4 loading failures caused by interrupted save recovery. Conflicting records are backed up automatically.
- Disabled Vulkan validation during normal PS4 gameplay to reduce overhead.
- Improved crash details and uploaded reports to help diagnose player issues.
- Runtime errors now identify missing or inaccessible files and explain how to restore them.

# EVAC PC LABEL v0.9.3

- 修复绊地狱等 PS4 游戏因存档恢复异常而卡在加载的问题。
- 关闭默认启用的 Vulkan 调试校验，减少 PS4 游戏的额外开销。
- 完善崩溃日志，上传时自动附带更多定位信息。
- 运行组件缺失或无法访问时，显示具体文件和处理方法。

## English

- Fixed interrupted save recovery that could leave Ketsui and other PS4 games stuck loading.
- Disabled Vulkan validation by default to reduce overhead in PS4 games.
- Improved crash logs and automatically included more diagnostic details in uploaded reports.
- Missing or inaccessible runtime files are now listed with steps to resolve the problem.

# 启动器封面布局（内部试用）

状态：11 款独立封面与内部网格已实现，现提供独立试用启动器。新版调整了间距、四列初始布局和窗口尺寸记忆；既有选择、启动、数据导入与横幅布局保持共用。

## 设计目标

从玩家“找到想玩的作品 → 选中 → 启动”的流程出发，让更多游戏在一个窗口内清楚展示。界面简洁、操作顺手，封面、标题和选择状态是主要视觉信息；常用设置容易找到，维护入口集中收起或放在底部。

封面布局独立于 PS2 运行时工作，覆盖合集全部作品。既有横幅布局继续可用，两套布局共享游戏清单、数据状态、配置及启动行为。

## 间距与初始窗口尺寸调整（2026-11-07）

按封面浏览重新调整间距、标题层级和初始窗口比例：

- 列间距由 18 增至 24，行间距由 12 增至 28，封面内边距由 7 增至 10。
  日文标题保留两行空间，英文副标题独立对齐，保持文字大小。
- 初始宽度以 192 逻辑像素的卡片、4 列为基准，客户区 912 逻辑像素。
  根据目标显示器 DPI 换算，并将含边框窗口限制在可用工作区宽度的 90% 内；
  空间不足时减少列数，不为保持列数缩小文字。首次打开时优先完整展示全部作品，
  上下留出桌面间距；完整高度放不下时限制为工作区高度的 90%，剩余作品滚动。
  已有手动保存的窗口尺寸仍优先恢复。
  完整展示时不预留原生滚动条宽度，避免隐藏滚动条后卡片变宽、增高而再次溢出。
- 11 款作品排列为 4＋4＋3，避免五列时最后只剩一款。1080p 的
  100%／125%／150% 缩放均以四列启动；手动拉宽窗口仍可增加到五列、六列。
- 大往生换成完整 PS4 盒绘，保留标题与主体，来源及 SHA-256 记录在 artwork.json。
- 正常关闭时记住窗口宽高；横幅、网格分别保存为 `[collection]` 下
  `launcher_banner_width/height` 和 `launcher_covers_width/height`（96 DPI 逻辑像素）。
  恢复时按当前 DPI 换算，并限制在当前显示器工作区内；最大化、最小化不覆盖正常尺寸。

尺寸、导航及素材检查通过；原生 CN／EN／JP 预览覆盖 1080p 的三种缩放及

## 布局方向

- [x] **封面网格。** 使用统一比例和尺寸的游戏封面，列数随可用窗口宽度调整。选取合适的官方素材，保持标题和主体完整；不同来源图片的留白、裁切和色调协调。参考图的深色背景可作为探索方向，整体主题与间距由效果图评估后确定。
- [x] **标题层级。** 沿用官方日文原名与较小的英文副标题；长名称保持卡片对齐，选中后能看到完整名称。卡片只保留有用信息，不增加日期、重复状态或固定操作说明占行。
- [x] **清楚的选择。** 悬停、键盘焦点与选中状态容易区分；保留统一的“启动游戏”主按钮。双击等快捷操作与现有行为保持一致，并检查滚动不误触启动。
- [x] **常用设置。** 重新安排语言、排行榜昵称、显示方式与启动区，使它们在小窗口中也能方便操作。配置、日志、游戏数据、刷新等维护功能集中于底部，不与封面争夺注意力。
- [x] **数据状态。** 缺少数据的游戏封面置灰，仍可选中并进入数据导入；补齐后刷新恢复。已有可识别数据但待完整校验、资源不完整、Coming Soon 和正在运行应分别正确表达，复用共同数据状态逻辑。
- [x] **适配与记忆。** 适配 1080p 可用工作区、高 DPI 和更高分辨率；窗口不超出屏幕。保存现有选中游戏，切换布局后继续选中同一作品；滚动定位使所选作品可见。

## 配置与开放方式

在现有 `user-data/config.ini` 的 `[collection]` 中选择布局：

```ini
[collection]
launcher_layout = banner
```

- `banner`：现有横幅列表，保持默认。
- `covers`：新版封面网格，供内部手动启用。

重启启动器应用此选项；未配置时继续使用现有布局。两种布局使用同一份配置、数据和存档，不需要换目录或另一个启动器 EXE。

新版先在内部测试，不自动切换现有玩家的界面，也不在界面或公开说明里主动展示／推广新布局。内部完成设计审查和实际操作验收后，再决定对外开放方式及是否调整默认值。

## 实施与内部验收

- [x] **先做设计。** 以现有作品及继续扩充后的游戏数量设计效果图，包含有数据、无数据、长标题、选中和运行中的状态。设计者先从真实使用流程自审，删去无助于选游戏和启动的文字与控件。
- [x] **共享行为。** 两种布局复用清单、数据检查、选中游戏、配置编辑、启动与进程状态；仅布局和绘制策略不同。所有游戏均遵循同样的交互规则。
- [x] **绘制效率。** 封面解码与缩放缓存复用；滚动不反复解码图片或扫描数据目录。控制图片内存，检查窗口缩放与 DPI 变化后的资源更新和画面清晰度。
- [x] **内部操作。** 用小型完整集合检查鼠标选择／双击、键盘选择／启动、滚动、缺数据导入／刷新、昵称保存、显示设置，以及游戏退出后再次启动。覆盖 CN／EN／JP 长标题、1080p／代表性 DPI，并快速检查更高分辨率；滚动经过卡片时输入框和显示设置不闪烁。
- [x] **切换回归。** 验证缺省保持 `banner`、手动切到 `covers`、关闭重开和切回旧版，配置及选中游戏正确保留。旧布局继续通过现有关键检查。
- [x] **内部交付。** 提供内部试用构建和两种布局截图，记录简洁度、可读性、操作效率及问题；完成内部验收后再决定公开发布内容。v0.9.7 本地程序包保留手动启用入口，默认横幅不变。最终构建的实际两种布局截图保存在 `.local/v097/screenshots/`，窗口保存／恢复检查 22 项通过。

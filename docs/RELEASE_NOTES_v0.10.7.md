# EVAC PC LABEL v0.10.7

## English

- All four PS2 games now have 99 save state slots. Press **F5** or **L1 + R1** to pause and save or load, including during Death Label launched from PS4 DaiOuJou. The menu remembers your last slot and gives you a three-second countdown after loading. [Controls](SETTINGS.en.md#ps2-save-states)
- Fixed the rotated or cropped Death Label picture on portrait displays. Death Label follows the PS4 game's screen settings and hides its side panels in portrait.
- Fixed a PS2 startup crash reported with Bandicam in Ibara and ESPGaluda.
- Pressing Start while moving up no longer triggers the default exit shortcut. To exit, hold Start first, then press Up.
- Added support for the US release of Ketsui Deathtiny (CUSA17078), including IKD 2007 SPECIAL, the optional X Arrange soundtrack and community leaderboards.
- Two players can now bind separate controls on one keyboard, including arcade panels that send keystrokes. You can also see which controller is assigned to each player and swap the two under **Controls**. [#42](https://github.com/zxl0714/EVAC-PC-LABEL/issues/42)
- When you exit the eandis version of SaiDaiOuJou, the launcher now cleans up a game process that stays in the background after its window closes. [#43](https://github.com/zxl0714/EVAC-PC-LABEL/issues/43)

## 简体中文

- 四款 PS2 游戏新增 99 个即时存档槽，从 PS4《大往生》进入的 Death Label 也能使用。按 **F5** 或 **L1 + R1** 即可暂停并存读档。菜单会记住上次使用的槽位，读档后倒数三秒再继续游戏。[按键设置](SETTINGS.md#ps2-即时存档)
- 修复竖屏游玩 Death Label 时画面转向或被裁切的问题。画面沿用 PS4 本篇的显示设置，竖屏时自动收起两侧仪表盘。
- 修复开启 Bandicam 时《铸蔷薇》和《ESPGaluda》可能在启动时闪退的问题。
- 向上移动时按 Start 暂停，不会再误触默认退出快捷键。要退出游戏，先按住 Start，再按方向上。
- 新增对美版《绊地狱》（CUSA17078）的支持，可游玩 IKD 2007 SPECIAL、选用自备的 X Arrange 曲包，并使用社区排行榜。
- 现在可以在同一键盘上分别设置 1P、2P 的按键，也适用于键盘模式的双人街机面板。使用两支手柄或摇杆时，可在按键设置中查看和互换 1P、2P。[#42](https://github.com/zxl0714/EVAC-PC-LABEL/issues/42)
- 退出 eandis 版《最大往生》后，如果游戏窗口已经关闭、进程仍留在后台，启动器会自动将其关闭。[#43](https://github.com/zxl0714/EVAC-PC-LABEL/issues/43)
